# AEC Multi-Agent Swarm (基于云边端架构的无人机施工“三控”协同中枢)

本项目旨在演示企业级 AI 架构在建筑工程施工领域的深度应用。项目构建了一个基于大模型多智能体（Multi-Agent）技术的智慧中枢，该中枢利用云边端混合算力，对无人机采集的多模态工地数据进行高并发处理，以长链推理技术破解施工现场进度、质量、安全（三控）协同管理的难题。

## 🎯 核心场景：三控合一深度整合
本项目突破了传统无人机单一视觉巡检的局限，利用多智能体网络对多源异构数据（3D点云、热成像、高清影像）进行高并发长链推理：
1. **施工进度控制 (Progress Control):** 调度无人机采集 3D 点云与 BIM 模型进行高精度比对，自动核算基坑土方开挖量，生成偏差预警与进度调整建议。
2. **施工质量控制 (Quality Control):** 针对高空外墙及基坑支护结构，解析无人机高清影像，识别混凝土裂缝、钢筋间距等关键质量指标是否符合现行国家标准。
3. **施工安全控制 (Safety Control):** 结合红外热成像与边缘行为分析，实时定位基坑临边防护缺失区域、作业人员未佩戴安全帽等违规行为，自动派发最高优先级告警指令。

## 🏗️ 架构特性
- **Async Orchestration:** 基于 `asyncio.gather` 实现“进度、质量、安全”三大控制流的非阻塞并发推演，极大提升了吞吐能力与计算效能（适配海量并发）。
- **Pydantic Validation:** 严格规范三大业务模块的数据流，确保系统与标准工程项目管理系统（PMIS）实现无缝对接。
- **Tool Calling:** 智能体可按需动态调用外部 BIM 数据库或工程规范 RAG 知识库。

## 🚀 快速开始
1. 复制 `.env.example` 为 `.env`
2. `docker-compose up -d` 启动基础大模型路由服务
3. `python async_orchestrator.py` 启动三控并发调度流
